# Сайт Владислава Златова — инструкция

Обычный статический сайт: HTML, CSS и немного JavaScript. Никаких сборок, npm и серверов.
Чтобы просто посмотреть — откройте `index.html` двойным кликом.

---

## 1. Как поменять цену, текст или ссылку

**Всё правится в одном файле — `config.js`.** Больше никуда лезть не нужно.

Откройте его любым текстовым редактором (Блокнот, TextEdit, VS Code) и найдите нужное место.
Файл разбит на понятные блоки и подписан по-русски.

### Поменять цену

Найдите блок `services` и нужную услугу:

```js
{
  price: 30, priceBgn: 58.67, mins: 60,
  name: { bg: "Мъжко подстригване", ... },
```

- `price` — цена в евро
- `priceBgn` — цена в левах
- `mins` — длительность в минутах

Меняете цифры, сохраняете файл, заливаете — готово.

### Добавить услугу

Скопируйте любой блок `{ ... }` целиком вместе с запятой в конце, вставьте рядом
и поменяйте текст. Порядок в списке = порядок на сайте.

### Убрать услугу

Удалите весь её блок `{ ... }` вместе с запятой.

### Поменять тексты на сайте

Блок `i18n` в конце файла. Внутри три раздела: `bg` (болгарский), `ru` (русский),
`en` (английский). Правите текст между кавычками. **Правьте все три языка**, иначе
на одном из них останется старый вариант.

## 2. Что нужно дозаполнить перед запуском

В `config.js` эти места помечены словом `TODO`:

| Что | Где | Что будет, если не заполнить |
|---|---|---|
| Телефон | `contacts.phone` | Кнопка «Обади се» просто не появится |
| Номер WhatsApp | `contacts.whatsapp` | Кнопка WhatsApp не появится |
| Точный адрес | `address.street`, `district` | На сайте будет честная фраза «адрес идёт в подтверждении» |
| Координаты точки | `address.lat`, `address.lng` | Карта ведёт в центр Варны |

Кнопки скрываются и появляются сами — ничего дополнительно включать не надо.
Вписали телефон → кнопка появилась.

**Когда появится адрес:** впишите `street`, `lat`, `lng`, поставьте `exact: true`,
и дополнительно добавьте адрес в разметку для Google — в `index.html` найдите блок
`"@type": "PostalAddress"` и допишите туда строку `"streetAddress": "ваш адрес",`.

**Координаты** проще всего взять так: открыть Google Maps, ткнуть правой кнопкой
в нужную точку — первая строка меню и есть широта и долгота.

## 3. Как выложить сайт в интернет за 5 минут

### Вариант A — Netlify (проще всего, бесплатно)

1. Зайти на [app.netlify.com](https://app.netlify.com), зарегистрироваться.
2. Нажать **Add new site → Deploy manually**.
3. Перетащить туда **папку `site` целиком** мышкой.
4. Через полминуты сайт живой по адресу вида `random-name.netlify.app`.

Чтобы обновить сайт потом — заходите в **Deploys** и снова перетаскиваете папку.

### Вариант B — Vercel

1. [vercel.com](https://vercel.com) → **Add New → Project**.
2. Загрузить папку или подключить репозиторий на GitHub.
3. Framework Preset: **Other**. Ничего настраивать не нужно.

### Вариант C — GitHub Pages

1. Создать репозиторий на GitHub, загрузить туда содержимое папки `site`.
2. **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Через пару минут сайт откроется по адресу `имя.github.io/репозиторий`.

## 4. Как подключить свой домен

1. Купить домен (Namecheap, GoDaddy, SuperHosting — любой).
2. В Netlify: **Domain settings → Add a domain** → вписать домен.
3. Netlify покажет, какие DNS-записи прописать у регистратора домена.
   Обычно это `A` на IP Netlify и `CNAME` для `www`.
4. Подождать до 24 часов. Сертификат HTTPS Netlify выпустит сам, бесплатно.

**После подключения домена обязательно замените адрес в трёх местах**
(сейчас там временный `https://zlatov.barber/`):

- `index.html` — строки с `canonical`, `hreflang`, `og:url`, `og:image`, `twitter:image`
- `sitemap.xml`
- `robots.txt`

Проще всего: открыть файл, нажать «Найти и заменить», заменить `https://zlatov.barber`
на свой адрес.

## 5. Как поменять фотографии

Фото лежат в папке `images`. У каждой по две-три версии разного размера —
браузер сам выбирает подходящую, чтобы сайт быстро открывался на телефоне.

Формат — **WebP**. Конвертировать бесплатно: [squoosh.app](https://squoosh.app).

Чтобы заменить фото работы:

1. Подготовьте картинку в пропорции **4:5** (вертикальная, например 720×900).
2. Сохраните в WebP в двух размерах: ширина 460 и 720 пикселей.
3. Назовите так же, как старые файлы: `work-fade-460.webp` и `work-fade-720.webp`.
4. Положите в `images` с заменой.

Чтобы добавить новую работу — положите файлы в `images` и допишите блок в `config.js`
в разделе `works`. Не забудьте `alt` — это подпись для поисковика и для незрячих.

## 6. Что где лежит

```
index.html          главная страница
config.js           ← все данные и тексты. Обычно правите только его
styles.css          оформление
script.js           логика: языки, меню, кнопки
404.html            страница «не найдено»
robots.txt          инструкция поисковикам
sitemap.xml         карта сайта
site.webmanifest    иконка при сохранении сайта на телефон
favicon.svg/.ico    иконка во вкладке браузера
apple-touch-icon.png иконка для iPhone
fonts/              шрифты (лежат локально, снаружи ничего не грузится)
images/             фотографии, изолинии, превью для мессенджеров
```

## 7. Отзывы — прочитайте перед публикацией

Секция отзывов собрана и работает, но **сейчас она в режиме макета**.
Карточки выглядят ровно так, как будут с настоящими отзывами — та же вёрстка,
та же плотность текста, разная длина. Отличие одно: в углу каждой карточки
стоит пометка «Макет», а под заголовком секции сказано, что это макет.
Тексты описывают сами себя и не выдают себя за слова клиентов.

В `config.js` есть блок `reviews`:

```js
reviews: {
  demo: true,
  items: []
}
```

**Когда появятся настоящие отзывы:**

```js
reviews: {
  demo: false,
  items: [
    { name: "Георги", source: "Google",
      text: { bg: "…", ru: "…", en: "…" } }
  ]
}
```

**Если отзывов пока нет:** поставьте `demo: false` и оставьте `items: []` —
секция и пункт в меню исчезнут сами, ничего удалять не нужно.

> **Важно.** Сюда попадают только настоящие отзывы настоящих клиентов.
> Публикация выдуманных отзывов в ЕС запрещена (директива Omnibus,
> в Болгарии транспонирована), и отвечает за это владелец сайта.
> Проще всего собрать честные: завести карточку в Google Business
> и попросить десяток постоянных клиентов написать пару строк.

## 8. Секция Kyone

Логотип и фото инструмента лежат в `images` как `kyone-mark-*.webp`
и `kyone-tools-*.webp`. Логотип показан ровно так, как его отдаёт бренд —
на своей белой подложке, без перекраски и обрезки букв.

- Адрес сайта партнёра — в `config.js`, поле `contacts.partnerUrl`.
- Тексты секции — ключи `kyoneTitle`, `kyoneLead`, `kyoneText` в блоке `i18n`.
- Если Kyone пришлёт логотип в векторе, положите файл как `kyone-mark.svg`
  и замените путь в `index.html` в блоке `<span class="plate__card">`.

**Убрать логотип, оставив текст:** в `index.html` удалите блок
`<span class="plate__card">…</span>` целиком. Останется только ссылка на kyone.com.

## 9. Мелочи, о которых стоит знать

- **Языки.** По умолчанию сайт открывается на болгарском. Выбор языка запоминается
  в браузере. Прямая ссылка на конкретный язык: `?lang=ru` или `?lang=en` в конце адреса.
- **Превью в мессенджерах.** Картинка `images/og.jpg`. Если поменяете — оставьте
  размер 1200×630. После замены Facebook и Viber кешируют старую версию, обновить
  можно через [developers.facebook.com/tools/debug](https://developers.facebook.com/tools/debug/).
- **Отзывы** сейчас в режиме образца — подробности в разделе 7 выше.
- **Аналитики и трекеров нет.** Если понадобится статистика посещений — скажите,
  подключим что-нибудь лёгкое.
- **Файлы не сжаты (не минифицированы)** специально — чтобы вы могли открыть
  и поправить их сами. Netlify и Vercel сжимают их на лету при отдаче,
  на скорость это не влияет.
